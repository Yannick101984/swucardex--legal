# Demande de suppression des données — SWU Cardex

*Dernière mise à jour : 3 octobre 2026*

SWU Cardex est une application développée par Yannick Le Pilouer, développeur indépendant. Cette page explique comment demander la suppression des données liées à l'application SWU Cardex (Android).

## 1. Aucun compte à supprimer

SWU Cardex ne demande pas de créer de compte. Il n'y a donc pas de profil à supprimer sur nos serveurs.

## 2. Données que vous pouvez faire supprimer

Le seul envoi de données de l'application vers le développeur est le **signalement d'erreur**, que vous déclenchez manuellement. Il peut contenir :
- le texte que vous avez rédigé ;
- le contexte de la carte concernée (nom, extension, numéro) ;
- le texte reconnu par le scanner et, si vous l'avez joint, le journal technique du scanner.

## 3. Comment demander la suppression

1. Rejoignez le serveur Discord de la communauté : https://discord.gg/T2uypjUJR3
2. Ouvrez un message privé à un membre de l'équipe, ou écrivez dans le salon de signalement en indiquant la date approximative du signalement et la carte concernée.
3. Précisez que vous demandez la suppression de vos données.

Nous supprimons le signalement et ses pièces jointes dans un délai de **30 jours** après réception de la demande.

## 4. Durée de conservation

- Les signalements d'erreur sont conservés **pendant 12 mois maximum** à compter de leur réception, pour permettre la correction des données de cartes.
- Passé ce délai, ils sont supprimés automatiquement, sauf demande de suppression anticipée.

## 5. Données stockées sur votre appareil

Les données de l'application (collection, decks, historique de scan, réglages) ne sont pas stockées sur nos serveurs. Elles sont supprimées :
- en désinstallant l'application ;
- ou, pour les seuls caches techniques, avec « Vider le cache » dans l'écran À propos.

## 6. Questions

Pour toute question sur cette procédure ou sur la politique de confidentialité, utilisez le même serveur Discord, ou consultez la politique : https://yannick101984.github.io/swucardex--legal/privacy-android
